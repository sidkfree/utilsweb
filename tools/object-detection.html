How it works

A YOLOS-tiny object detection model is loaded into your tab via transformers.js + ONNX Runtime Web. Each video frame is captured, fed to the model, and the predicted bounding boxes are drawn on a transparent canvas overlaid on the video. WebGPU is used when available (much faster); WASM otherwise.

Detects: 91 COCO classes — person, car, bicycle, dog, cat, bottle, laptop, book, chair, phone, tv, plant, etc.

Privacy: the model runs locally on your device. Your camera feed never leaves your browser — there is no network request once the model is cached. That's a meaningful difference vs cloud APIs that ingest your video.

About Live Object Detection

Frequently asked questions

Is Live Object Detection free to use?

Yes. Live Object Detection is completely free, with no sign‑up, no account, and no usage limits. Like every tool on UtilsWeb, it is supported by unobtrusive ads so it can stay free for everyone.

Does Live Object Detection upload my data to a server?

No. Live Object Detection runs entirely in your browser. Anything you enter or load is processed on your own device and is never uploaded, stored, or sent to us. When you close the page, the data is gone.

Do I need to install anything to use Live Object Detection?

No installation is required. Live Object Detection works directly in any modern web browser on desktop or mobile. Because it is client‑side, it even keeps working if you lose your internet connection after the page has loaded.

Is Live Object Detection accurate and safe to use?

Live Object Detection uses well‑established methods and runs locally, so there is no risk of your information leaking to a third party. For important financial, medical, or legal decisions we still recommend verifying results independently.

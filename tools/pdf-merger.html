How it works

Each PDF is parsed in your browser using pdf-lib (a pure-JavaScript PDF toolkit). The pages are copied into a fresh document in the order you set and saved to a single .pdf file. Nothing is uploaded — disconnect from the internet after the page loads and it still works.

Tip: drag the rows by the ⋮⋮ handle (or anywhere on the row) to change the order. Click ✕ on a row to remove a file from the list. Page counts are read from the PDF metadata.

Scope: form fields, annotations, bookmarks and embedded fonts are preserved. Encrypted PDFs are not supported — remove the password first if your file has one.

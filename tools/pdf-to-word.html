How it works

The PDF is parsed in your browser using PDF.js. Each page's text is read top-to-bottom and written into a fresh Word document with the docx library. The file never reaches any server — close this tab and it's gone.

Scope: this is a text-only conversion. Fonts, exact layout, images, multi-column flow and embedded tables are not preserved — that level of fidelity needs Microsoft Word's own "Save as DOCX" feature. For privacy-sensitive copy of the text content, this tool is faster and 100% private.

Image Compressor

Shrink JPG, PNG and WebP files without uploading them. Quality slider, optional resize, before/after.

🖼️
Drop images here or click to browse
JPG · PNG · WebP. Tweak quality, resize, and download — nothing leaves your browser.

How it works

Each image is decoded into a hidden <canvas> in your browser, optionally resized, and re-encoded with the native canvas.toBlob() API at the quality you pick. Nothing is uploaded — you can disconnect from the internet after the page loads and it still works. PNG is lossless so the quality slider has no effect for PNG output; switch to JPG or WebP to get real size savings.

Tip: WebP usually gives the smallest file at a given quality. JPG is the safest if you need to send the file to old software. PNG only makes sense if the image has transparency you must preserve.

Scope: EXIF metadata (camera GPS, date) is stripped during re-encoding — that's actually a privacy upside. Animated GIFs are not supported (only the first frame would survive).

🔒 100% client-side — nothing ever leaves your browser.

CIDR / Subnet Calculator

Network, broadcast, host range, mask for any IPv4 CIDR.

How it works

IPv4 bit math — network = ip & mask, broadcast = network | ~mask. /31 and /32 are treated as point-to-point (no host gap).

🔒 100% client-side — nothing ever leaves your browser.

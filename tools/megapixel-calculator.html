Megapixel / Print Size

Maximum print size at a given DPI from any image resolution.

How it works

MP = pixels / 10⁶. Print size (in) = pixels / DPI. 300 DPI = sharp photo print; 150 DPI = poster from arm's length.

🔒 100% client-side — nothing ever leaves your browser.

BIP39 Mnemonic Generator

Generate a fresh 12 / 15 / 18 / 21 / 24-word seed phrase. Pure browser entropy.

⚠ Never paste a real wallet seed into any web page — including this one. Use this tool only for testing.

How it works

Uses the standard BIP-0039 English wordlist with entropy from crypto.getRandomValues via the bip39 library. Browser-only — no network call at generation time.

🔒 100% client-side — nothing ever leaves your browser.
